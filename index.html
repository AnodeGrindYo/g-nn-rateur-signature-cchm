Conseil pour Outlook et Gmail. Téléchargez un fichier par employé, puis ouvrez-le dans un navigateur, copiez la signature affichée et collez-la dans l’éditeur de signatures de la messagerie (Outlook : Fichier › Options › Courrier › Signatures). Avec Outlook, ce collage permet d’intégrer le logo au message : sinon Outlook bloque les images distantes chez les destinataires. Le fichier exporté contient uniquement la signature, pas l’éditeur.
ATTENTION : Pour Outlook Web, il faut aller dans Fichier → Paramètres → Comptes → signatures et copier directement le rendu html de la signature, pas le code html de la signature
